How to play
  1. You start on one article and have to reach the goal article.
  2. You can only travel by clicking links in the list — no search, no back door. It is Wikipedia with the address bar taken away.
  3. Par is the shortest route that actually exists. Beat it and you cannot; match it and you found an optimal path.
  4. The number beside each link is its inbound link count — how many articles point at it. Big numbers are hubs: fast, but everyone goes that way.
  5. Hub exclusion locks the biggest articles so you cannot route through "United States" every time. Par is recomputed with the same lock, so the target stays fair.
  6. Back is free and does not cost a click. The clock keeps running, which is the real cost of a wrong turn.
  7. Pause stops the clock and hides the links, so it is not a way to think for free.
